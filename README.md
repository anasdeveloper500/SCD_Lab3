# Lab Task 03 – JUnit Unit Testing

## Subject

Software Construction

## Objective

The objective of this lab is to understand and implement unit testing in Java using the JUnit framework within NetBeans IDE. This lab focuses on creating Java classes, writing automated test cases, verifying expected outputs, handling exceptions, and interpreting test results.

## Lab Tasks Completed

### Lab Task 1 – Temperature Converter

Implemented temperature conversion methods for Celsius to Fahrenheit, Fahrenheit to Celsius, and Celsius to Kelvin. JUnit tests were used to verify known temperature values and conversion accuracy.

### Lab Task 2 – Bank Account Operations

Implemented bank account deposit and withdrawal operations. JUnit tests verify valid deposits, valid withdrawals, overdraft conditions, and negative deposit exceptions.

### Lab Task 3 – String Utility (Palindrome Checker)

Implemented a palindrome checker that supports case-insensitive checking and handles null and empty inputs. JUnit tests verify palindrome and non-palindrome cases.

### Lab Task 4 – Simple Timer Utility

Implemented a method to calculate the number of seconds between start and end values. JUnit tests verify normal cases, boundary conditions, and invalid input exceptions.

### Lab Task 5 – Shopping Cart

Implemented basic shopping cart operations including adding items, removing items, counting items, and clearing the cart. JUnit tests verify the functionality of each operation.

## Homework Completed

### Homework 1 – Enhanced Calculator

Implemented power and modulus operations. JUnit tests cover normal, boundary, and exceptional cases. The implementation also uses @BeforeEach and @AfterEach annotations.

### Homework 2 – Account Validation

Implemented bank account validation rules including valid deposits, withdrawals, overdraft prevention, and account activity status based on the remaining balance.

### Homework 3 – String Utility Testing

Implemented palindrome checking, vowel counting, and anagram checking. JUnit tests cover normal cases, null and empty inputs, case-insensitive operations, and different vowel-count scenarios.

## Technologies Used

* Java
* JUnit 5
* Apache NetBeans IDE
* GitHub

## How to Run the Project

1. Clone or download this repository.
2. Open the required project in Apache NetBeans IDE.
3. Make sure JUnit 5 is available in the project libraries.
4. Run the Java application if required.
5. Right-click on the test file or project and select Run Tests.
6. Check the JUnit test results window to verify that all tests pass.

## Testing

JUnit 5 was used for automated unit testing. Different assertions such as assertEquals, assertTrue, assertFalse, and assertThrows were used to verify expected results and exceptional conditions.

## Conclusion

This lab provided practical experience in unit testing using JUnit. It demonstrated how automated testing can improve software reliability by checking normal cases, boundary conditions, and invalid inputs.
